# RE:BORN 지식 Vault

공식 폐업 절차와 지원사업 공고를 함께 검토하는 팀 문서입니다.
데이터 기준은 [schema_table.md](../../schema/schema_table.md)이며,
Vault 문서 작성만으로 DB에 행을 만들거나 Case 상태를 변경하지 않습니다.
Vault 밖 저장소 문서의 상대 링크는 코드 편집기나 저장소 화면에서 엽니다.

## 읽는 순서

1. [[폐업절차/공식 폐업 절차]]에서 업무별 공식 출처와 확인할 조건을 읽습니다.
2. [[지원사업/목록]]에서 실제 API로 수집한 공고를 엽니다.
3. [[검수 안내]]에 따라 공식 원문·첨부·수정 공고를 확인하고 DB 항목과 연결합니다.
4. 사람 검수가 끝난 항목만 [[지원사업/검수완료/README|검수완료 폴더]]에 둡니다.

## 현재 자료 상태

| 구분 | 상태 |
|---|---|
| 공고 수집 | 2026-09-20 22:02 KST 기업마당 API 실제 3회 호출, 모두 HTTP 200 |
| 미검수 지원사업 | 제목에 폐업 관련 표현이 있는 실제 공고 7건, 공고 ID로 중복 제거 |
| 검수 완료 지원사업 | 0건 — 사람 검수·BE 실제 ID/UUID 매핑 전 |
| 공고 최신성 | `UNKNOWN` — API 수신 시각을 최신 정책 확인일로 바꾸지 않음 |
| 첨부파일 | API가 제공한 링크만 보존, PDF 원문 다운로드·검수 미실행 |

검색은 일부 키워드와 건수 상한을 사용한 수집입니다. 모든 폐업지원 공고를 망라하거나,
검색된 사업이 현재 접수 중·사용자에게 적용된다는 뜻이 아닙니다.
`미검수`의 JSON 블록은 발견 자료 보존용이고 Agent의 검수된 지원조건 조회 형식과 다릅니다.
