# 공식 폐업 절차

[[시작하기|Vault 시작하기]] · [[공식 폐업 절차#업무별 공식 출처|업무별 공식 출처]]

> **팀 검수 전** — 공식 자료를 바탕으로 만든 팀 Wiki 진입점입니다.
> 공식 원문 확인일: 2026-09-20, [상세 정리 문서](../../official-closure-procedure.md) 기준.
> 확인일은 법령 시행일이나 사람 검수 완료일이 아닙니다.

폐업을 결정한 **임차형 소규모 비프랜차이즈 카페**에서 무엇을 확인해야 하는지 정리합니다.
세무 안내는 개인사업자 중심입니다. 상세 절차·예외·근거와 미확인 범위는
[공식 폐업 절차 원본문서](../../official-closure-procedure.md)를 함께 읽습니다.

## 핵심 경로

**상태 확인 → 필요한 현실 행동 → 실행 결과 확인 → 다음 행동 재검토** 순서로 진행합니다.
아래 항목 번호는 검토를 돕기 위한 것이며, 모든 사업장에 고정된 법정 처리 순서가 아닙니다.

1. **점포 반환 조건 확인:** 임대차 종료 조건과 원상복구 범위를 확인합니다.
   보증금 미반환·분쟁이 있으면 신고 의무와 권리보전 방법을 전문가·관할기관에 함께 확인합니다.
2. **철거비 지원을 검토하면 조건부터 확인:** 최신 공고와 첨부에서 신청·철거 순서와 증빙을 확인합니다.
   모든 사업에 사전 승인이 필요하다고 가정하지 않습니다.
3. **직원이 있거나 최근 퇴직했다면 정산 확인:** 근로관계 종료, 임금·퇴직급여, 가입 보험을 구분합니다.
   현재 직원 수가 0명이어도 기존 가입 관계와 미처리 의무가 정리됐는지 확인합니다.
4. **사업자등록·식품영업 폐업신고 확인:** 대상 업종의 통합 접수 가능성을 확인하고 각 처리 결과를 확인합니다.
5. **세금·보험·점포 반환의 남은 일 확인:** 신고 접수만으로 세금 납부, 보험 정리, 보증금 반환이나
   Case 전체가 완료됐다고 판단하지 않습니다.

여러 업무는 함께 진행할 수 있습니다. 예정 폐업일을 실제 폐업일로 바꾸어 기한을 계산하지 않고,
확인되지 않은 조건은 `UNKNOWN`으로 남깁니다.

## 팀 검수에서 확인할 조건

- **신고와 납부의 관계:** 생활법령 페이지 소제목만으로 세금 완납을 폐업신고의 필수 선행 조건으로
  만들지 않습니다. 상세 본문과 실제 과세유형·폐업일을 함께 확인합니다.
- **보험별 적용 범위:** 국민연금 안내를 건강보험·고용보험·산재보험의 동일 기한·서류로 확대하지 않습니다.
  나머지 보험은 각각의 공식 근거가 더 필요합니다.
- **지원사업의 최신성:** 위 기업마당 링크는 원공고입니다. 최신 수정 공고·첨부·접수 가능 여부와 예산 상태,
  해당 사업자의 조건은 별도 확인해야 합니다. 공고 수집이나 Wiki 작성은 선정·지급 확정이 아닙니다.
- **날짜와 금액:** 이 진입점에서 새로운 법정기한·신청일·지원금액을 만들지 않습니다.
  실제 날짜를 안내하려면 검수된 공식 규칙과 확인된 기준 사실이 필요합니다.

## Agent와 연결되는 범위

이 노트는 팀이 읽는 절차 안내이며, `reborn-support-entry`를 담는 지원사업 조회 노트가 아닙니다.
이 파일을 만들었다고 절차 스냅샷의 사람 검수가 끝나거나 DB 상태가 바뀌지 않습니다.
검수 담당자와 검수일을 AI가 대신 채우지 않습니다.

절차 데이터를 반영하는 방법은 [절차 지식 관리](../../procedure-knowledge.md),
지원사업 노트의 읽기 계약은 [지원사업 Wiki 조회 경로](../../support-wiki.md)를 따릅니다.
Vault 안의 공고 목록과 작업 안내는 [[시작하기]]에서 이어갑니다.
