# 검수 완료 지원사업

[[시작하기]] · [[검수 안내]] · [[지원사업/목록]]

현재 Agent가 조회할 검수 완료 노트는 **0건**입니다.
이 안내 파일은 `SUPPORT_ITEM.uuid` 파일명이 아니므로 exact lookup 대상이 아닙니다.

실제 DB ID·UUID, 공식 근거, 사람이 검수한 조건과 검수 기록을 갖춘 노트만 이 폴더에 둡니다.
Agent CLI 연결 시 `--support-wiki docs/agent/obsidian/지원사업/검수완료`를 지정합니다.
`미검수` 폴더를 이 옵션에 연결하거나 노트 이름만 UUID로 바꾸어 검수를 대체하지 않습니다.

형식과 연결 조건: [지원사업 Wiki 조회 경로](../../../support-wiki.md).
