# RE:BORN Obsidian Vault

Obsidian에서 **Manage Vaults → Open folder as vault**로 이 폴더
(`docs/agent/obsidian`)를 열고 [시작하기](./시작하기.md)를 읽습니다.
별도 플러그인 없이 Markdown과 내부 링크로 사용할 수 있습니다.
Vault 안의 문서는 Obsidian 내부 링크로 연결됩니다. `schema_table.md`처럼 Vault 밖의
저장소 문서를 참조하는 상대 링크는 코드 편집기나 저장소 화면에서 열어 주세요.
폴더를 Vault로 여는 방법과 `.obsidian` 설정 폴더는
[Obsidian 공식 안내](https://obsidian.md/help/manage-vaults),
[설정 폴더 안내](https://obsidian.md/help/configuration-folder)를 따릅니다.

실제 기업마당 API에서 수집한 공고는 `지원사업/미검수/`에 있습니다.
수집 자료는 정책 검수를 마친 지원사업이 아니며, 현행 접수·자격·금액을 확정하지 않습니다.
실제 DB 식별자와 사람이 검수한 조건을 갖춘 노트만 `지원사업/검수완료/`에 둡니다.
현재 검수 완료 지원사업은 **0건**입니다.

Agent 조회 계약과 수집 명령은 [지원사업 Wiki 문서](../support-wiki.md)에 있습니다.
이 Vault에 Case·계약서·사업자 개인정보·API 키를 넣지 않습니다.
