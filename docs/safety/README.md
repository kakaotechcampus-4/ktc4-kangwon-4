# 리본 안심가이드

운영철학과 안전한 이용 방법을 이용자에게 설명하는 공개 안내입니다. **`/safety/`**에서 로그인 없이 열립니다. [카톡 안녕가이드](https://talksafety.kakao.com/)의 정보 구성과 넓은 여백·큰 제목·시각 자료를 참고하고, 리본의 개인 카페 폐업 지원 흐름과 주황색 브랜드에 맞춰 새로 작성했습니다.

## 구성과 근거

| 화면 | 리본에 맞춘 내용 |
| --- | --- |
| 홈 | 타이포그래피 소개 영상과 준비·완료 구분, 절차 안내 종료, 내 정보 확인의 큰 안내 3개 |
| 운영철학 | 폐업 여부를 대신 결정하지 않고 다음 할 일을 함께 정리하는 이유 |
| 안심 이용 | 로그인, 결과 정정, 서류 확인, 기관 제출과 오류 복구 |
| 운영 기준 | 현재 지원 대상과 제공 범위, 자동 처리 중단의 의미 |
| AI와 검수 | 안내·검수 과정, 안전 검사와 자동 감지의 한계 |
| 정보 보호 | 입력·AI 판독·제출 파일의 가림 차이, 소유권·저장·삭제의 실제 범위 |
| 사례와 질문 | 예시 12개, 분류 필터와 펼쳐 읽기 |

카카오톡의 채팅·신고·계정 제재 정책을 리본의 기능처럼 옮기지 않았습니다. 카카오의 운영 보고서에 해당하는 리본 안내는 실제 개발 검증·변경 기록으로 연결합니다. 미측정 운영 통계·보안 인증·보관 기한·실시간 상담을 약속하지 않습니다. 이 페이지는 이용약관이나 개인정보처리방침을 대신하지 않습니다.

각 화면의 구현 근거는 `content.mjs`의 `sources`에 기록했습니다. 특히 서류함 삭제는 목록 제외·점검 무효화이며 저장 파일 전체의 영구 삭제가 아닙니다. 현재 동작이 달라지면 안내도 함께 수정해야 합니다.

2026년 11월 9일 `develop 52807ae`를 기준으로 준비·제출·완료 버튼과 진행 상태, 절차 안내 종료의 의미, 내 정보·로그아웃, 오류 복구와 DB 서류함의 저장 범위를 갱신했습니다. 홈의 세 가지 안내에서 관련 내용을 자세히 볼 수 있습니다.

## 실행과 갱신

```sh
cd frontend
npm run dev
# http://localhost:5173/safety/

npm run docs:check
npm run docs:build
npm run build
```

`content.mjs`는 사람이 검토하는 원칙·설명·질문, `safety.css`와 `safety.js`는 화면과 검색·분류 동작입니다. `scripts/build-safety.mjs`를 개발 문서 생성기가 함께 호출해 `frontend/public/safety/`를 생성합니다. 생성물을 직접 수정하지 않습니다. 검색은 공개 안내만 읽으며 서비스 API·추적·사용자 데이터 저장 기능은 추가하지 않았습니다.

**11월 11일까지 서비스 변경 시 개발 문서와 함께 이 안내도 갱신**합니다. 서류 가림·삭제, 지원 범위, 안전 검사와 정정·복구 동작을 중점 확인합니다. FE 소스를 바꾸면 [개발 문서 갱신 절차](../developers/README.md)에 따라 계약·소스 해시를 다시 내보냅니다. 검증 기록은 `validation.json`에 남깁니다.
