## 원고와 생성 도구

`content.py`는 화면별 원고와 점검 시나리오, `build_guide.py`는 PDF·HTML·Markdown·CSV 생성기입니다. `capture_screens.py`는 로컬 5173 포트의 미리보기 화면을 캡처합니다. `screenshots.json`·`api-inventory.json`·`roadmap-tasks.json`은 캡처와 구현 목록입니다.

재생성에는 Python 3.12, ReportLab·Pillow·Playwright가 필요합니다. 캡처는 macOS Chrome 경로, PDF는 로컬 NanumBarunGothic 글꼴 경로를 사용하므로 다른 PC에서는 경로를 조정하세요.
