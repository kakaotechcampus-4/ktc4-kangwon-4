재방문에 필요한 맥락#

지난번 입력과 판단 결과를 한 흐름으로 보여줘 진행 상황을 복원합니다. 사용자 작업 기록과 개발용 모델 추적은 서로 다릅니다.

기록되는 이벤트#

진단, 결과 전달, 충돌 선택, 체크·취소, 심사 결과, 서류 업로드·점검과 새 작업 안내, 등록된 절차 안내 종료(PROCEDURES_COMPLETED)를 저장 상태에서 조립합니다. 홈의 활동 띠는 같은 기록 중 리본이 한 일을 사용합니다.

표시와 예외#

필요 없는 원문을 기록 탭에 반복 노출하지 않습니다. 기록 없음과 조회 실패를 나눠 표시하고 다른 회원의 Case 기록은 읽지 않습니다. 머리말의 내 정보는 /mypage로 연결되며 기존 /notifications 화면은 제거됐습니다.
