카카오 앱#

카카오 로그인 사용 설정, Redirect URI와 필요한 동의항목을 확인합니다. 현재 BE는 profile_nickname을 요청합니다. 변경되는 카카오 콘솔의 세부 메뉴 경로는 공식 설정 문서를 기준으로 확인합니다.

공식 설정 문서 ↗

리본 서버#

아래 값은 서버 설정입니다. 실제 비밀값을 문서·공개 FE 환경변수·로그에 넣지 않습니다.

설정역할
KAKAO_CLIENT_ID카카오 앱 REST API 키
KAKAO_CLIENT_SECRET토큰 교환의 client_secret
KAKAO_REDIRECT_URI카카오에 등록한 콜백 주소
JWT_SECRET_KEY리본 자체 JWT 서명 키

로컬과 배포#

로컬 실제 로그인에서는 BE의 Redirect URI와 카카오 등록값을 http://localhost:5173/login/callback에 맞춥니다. 배포 BE가 배포 콜백 주소 하나를 쓰고 있다면 로컬로 돌아오지 않습니다. 개발 가짜 로그인은 화면 검토에만 사용합니다.
