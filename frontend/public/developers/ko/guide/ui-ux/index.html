화면과 UX

40~50대 개인 카페 사장님을 고려한 글자·버튼·정보 배치와 설계 이유를 설명합니다.

코드 기준 c01bf12 · 확인 2026-11-10

40~50대 핵심 사용자를 위한 화면 원칙#

폐업 절차를 직접 챙기는 40~50대 사장님의 읽기·선택·입력 부담을 줄이는 것을 목표로 합니다. 홈에서는 지금 먼저 확인할 행동 하나를 강조하고, 전체 진행은 로드맵으로 분리합니다. 질문은 한 장씩 보여주며 모름·해당 없음·확인 필요를 구분합니다.

  • 질문은 사용자가 답할 수 있는 내용만 받습니다.
  • 서버가 확정한 값만 표시하고 저장 응답 전에 체크를 바꾸지 않습니다.
  • 중요한 선택은 미리 고르지 않습니다.
  • 실패하면 입력을 보존하고 가능한 복구 행동을 안내합니다.

글자·버튼·배치의 구현 근거#

큰 핵심 글자와 버튼, 일관된 글꼴, 단계별 질문으로 지금 읽고 실행할 내용을 구분합니다. 아래 값은 현재 서비스 컴포넌트 기준입니다.

설계현재 구현목적
글꼴Pretendard · 한국어 단어 중간 줄바꿈 방지한글 안내를 일관되게 읽기
홈 할 일 제목26px · 줄높이 36px핵심 행동을 먼저 찾기
주요 버튼기본 높이 56px·글자 18px / 큰 버튼 60px·19px주요 행동을 찾고 누르기
질문과 입력질문을 나눠 표시 · 선택형 · 모름 · 직접 입력기억·타이핑·불확실한 응답 부담 줄이기
정보 배치현재 행동 카드 · 별도 로드맵 · 홈/서류함/기록 하단 탭지금 할 일과 전체 진행 구분하기

화면과 이동#

홈·서류함·기록은 하단 탭입니다. 머리말의 사람 버튼은 /mypage의 내 정보로 연결됩니다. 로드맵과 개별 작업은 탭 밖에서 열며, 충돌 확인은 정상 순서의 중간 단계가 아니라 예외 분기입니다.

경로화면
/login · /login/callback소개와 로그인 처리
/cases/new조건별 상황 진단
/case · /task현재 Case와 할 일 상세
/results · /replan실행 결과와 반영 내용
/confirm기존값과 새값 충돌 확인
/roadmap · /roadmap/:taskId전체 순서와 작업별 입력
/docs · /docs/check · /docs/done서류함·점검·제출 파일
/log · /mypage작업 기록·내 정보와 로그아웃

공개 안심가이드의 소개 영상과 안내#

안심가이드 홈은 사용자가 제공한 12초·1920×1080 타이포그래피 MP4와 준비·완료 구분, 절차 안내 종료, 내 정보 확인의 세 가지 안내로 구성합니다. 각 안내는 설명과 미리보기 화면을 나란히 보여주고 상세 안내로 연결합니다. 영상은 무음 반복 재생과 멈춤·재생을 지원하며, 동작 줄이기 설정에서는 자동 재생하지 않습니다. 배경 탭이나 화면 밖에서는 재생을 멈춥니다. 영상은 브랜드 소개이며 실제 상담 화면이나 처리 상태가 아닙니다.

읽기와 접근성#

Pretendard와 의미 기반 색·글자 토큰을 사용합니다. 입력 글자는 16px 이상, 버튼·선택 항목에는 이름과 상태를 제공합니다. 움직임 줄이기 설정을 따르고 시트·키보드 포커스를 고려합니다.

40~50대 사용자에게 확인할 과업#

모바일 사용 경험이 다른 핵심 대상에게 도움 없이 진행하도록 하고, 어려운 글자·잘못 누른 곳·도움 요청과 과업 설명 여부를 기록합니다. 아래는 수행할 확인 과제이며 통과한 테스트 결과가 아닙니다.

검증할 UX 과제#

11~15px 보조 글자도 남아 있어 모든 글자가 큰 것은 아닙니다. 작은 화면과 확대에서 읽기·버튼 잘림을 확인해야 합니다. 5단계 번호가 철거와 영업 종료 순서를 오해하게 할 수 있고 정상 반영 후 [맞아요]는 저장 전 승인이 아닙니다. 이러한 안내가 실제 사장님에게 이해되는지도 확인합니다.

설계 의도와 검증 결과

40~50대는 핵심 설계 대상이며 연령만으로 사용 능력을 단정하지 않습니다. 현재 해당 연령대의 고객 수요나 사용성 개선 효과가 실험으로 입증됐다는 뜻은 아닙니다.
