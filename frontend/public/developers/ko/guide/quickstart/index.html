코드 기준 c01bf12 · 확인 2026-11-10

요구 사항#

FE는 Node 20.19 이상 또는 22.12 이상, BE는 Python 3.12와 MySQL 8.0.46을 사용합니다. 정확한 패키지 버전은 lockfile과 requirements가 기준입니다.

구분실행 위치역할
Frontendfrontend/React·Vite 화면과 /api 프록시
Backend와 Agentbackend/FastAPI·LangGraph, 같은 Python 프로세스
MySQL루트 ComposeCase·이력·근거·회원 상태
문서frontend/public/developers/빌드 때 생성되는 공개 정적 문서

Frontend 실행#

처음 설치하거나 CI에서는 lockfile 그대로 설치합니다. FE 기본 API 주소는 /api이며, 로컬 BE에 직접 붙일 때만 frontend/.env.local에 공개 API 주소를 설정합니다.

Shell
cd frontend
npm ci
npm run dev

Backend 실행#

AI 연결은 루트 .env.example, 서버 인증·DB는 backend/.env.example을 보고 각각 .env와 backend/.env를 준비합니다. 서류 기능은 OCR 준비 명령을 한 번 실행합니다. 데이터베이스와 문서 볼륨의 대상부터 확인합니다.

주의

ENVIRONMENT=dev의 앱 시작에는 테이블 초기화가 있습니다. 운영 데이터베이스에 연결한 상태로 개발 서버를 시작하면 안 됩니다.

Shell
# 저장소 루트에서 DB 실행
docker compose up -d db

# Python 3.12 환경에서
cd backend
python -m pip install -r requirements.txt
python scripts/setup_agent_ocr.py
python -m uvicorn app.main:app --reload

카카오 로그인과 로컬 미리보기#

실제 로그인은 카카오 앱의 Redirect URI, KAKAO_REDIRECT_URI와 브라우저 콜백 주소가 일치해야 합니다. 가짜 로그인은 개발·허용된 Preview에서 화면을 보는 기능이며 실제 인증 성공의 증거가 아닙니다.
