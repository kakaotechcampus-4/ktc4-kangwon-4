상황 진단과 Case

가게의 기본 조건을 받고 첫 판단을 시작합니다.

코드 기준 4188520 · 확인 2026-11-11
이해하기REST API에러 코드

이 기능이 필요한 이유#

임차·직원·대출·보험 이력에 따라 해야 할 일이 달라집니다. 먼저 버튼과 날짜 선택으로 상황을 받고, 확인하지 못한 값은 모름으로 남깁니다.

진단 질문#

앞 답으로 불필요해진 질문은 생략합니다. 현재 직원이 0명이어도 과거 고용 이력을 별도로 확인합니다. 최초 진단에서 과거 직원·사업장 보험 가입 이력은 예·아니요로 받습니다. API에서 생략한 null과 아니요인 false는 구분합니다.

입력묻는 조건과 의미
업종·가게 상황개인 카페(프랜차이즈 카페·다른 음식점은 준비 중으로 보이며 고를 수 없음), 임차·직원·대출·서비스 계약
월세·복구 조항빌린 가게일 때만 질문, 조항과 실제 범위는 별개
직원·보험현재 인원과 과거 고용·사업장 보험 이력 구분
폐업 시기이번 달·다음 달·미정, 실제 폐업일과 별도

생성과 첫 판단#

POST /cases가 회원당 Case 하나와 PENDING 입력 이력을 만듭니다. 첫 판단은 배경에서 진행하고, 홈은 GET /cases로 현재 상태를 조회합니다. 계획 시기와 신고할 실제 폐업일은 구분해 저장합니다.

  1. 진단 답을 확인합니다.
  2. Case와 첫 판단 이력을 저장합니다.
  3. 요청 커넥션을 반환하고 판단을 시작합니다.
  4. 홈에서 처리 상태와 다음 할 일을 확인합니다.

테스트 케이스#

진단 답은 화면 이동·새로고침과 실패 뒤에도 이어 쓸 수 있어야 합니다.
