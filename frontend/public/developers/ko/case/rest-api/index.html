Case REST API

가게를 생성하고 현재 상태·판단을 조회합니다.

코드 기준 4188520 · 확인 2026-11-11
이해하기REST API에러 코드
요청 경로와 인증

표는 Backend 경로입니다. 예제의 REBORN_API_BASE_URL은 Backend 주소(로컬 기본 http://localhost:8000)로 설정합니다. FE의 같은 출처 프록시 주소를 쓸 때는 /api까지 포함합니다. 리본 API에는 리본 자체 JWT를 Access-Token 헤더로 보냅니다. 카카오 토큰과 구분하세요.

Case 생성

Case와 첫 PENDING 이력을 저장하고 배경 판단을 시작합니다. 회원당 Case는 하나입니다.

메서드URL인증 방식
POST/cases리본 Access-Token

요구 사항

유효한 리본 Access-Token이 필요합니다. 생성은 아직 Case가 없는 회원이 사용하고, 조회는 Case가 없으면 case: null을 반환합니다.

현재 Case 조회

현재 확정 상태와 최신 판단을 조회합니다. Case가 없을 때의 case:null을 오류와 구분합니다.

메서드URL인증 방식
GET/cases리본 Access-Token

요구 사항

유효한 리본 Access-Token이 필요합니다. 생성은 아직 Case가 없는 회원이 사용하고, 조회는 Case가 없으면 case: null을 반환합니다.

요청

헤더설명필수
Access-Token리본이 발급한 해당 유형의 JWTO

요청 본문 없음

cURL · 자리 표시자를 바꾸어 사용
curl -X GET "${REBORN_API_BASE_URL}/cases" \
  -H "Access-Token: ${ACCESS_TOKEN}"
