요청 경로와 인증

표는 Backend 경로입니다. 예제의 REBORN_API_BASE_URL은 Backend 주소(로컬 기본 http://localhost:8000)로 설정합니다. FE의 같은 출처 프록시 주소를 쓸 때는 /api까지 포함합니다. 리본 API에는 리본 자체 JWT를 Access-Token 헤더로 보냅니다. 카카오 토큰과 구분하세요.
