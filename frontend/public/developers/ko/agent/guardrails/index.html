근거와 검수

검수되지 않은 초안이 확정 상태로 저장되지 않게 합니다.

코드 기준 4188520 · 확인 2026-11-11

근거#

공식 자료는 출처·버전·검수·최신성·내용 hash를 확인합니다. 자료가 없으면 다른 자료로 채우지 않습니다. 사용자 입력에는 원문 근거를 연결하고 다른 Case 자료를 섞지 않습니다.

검수 증명#

ReviewProof는 같은 Case·snapshot·입력·초안을 묶습니다. 초안이나 선행 결과가 바뀌면 과거 PASS를 재사용할 수 없습니다. Agent는 변경 후보를 반환하며 저장은 BE가 맡습니다.

DB와 이력#

현재 상태는 Case, 입력·판단 상태와 다음 행동은 CaseHistory에 둡니다. 공식 문서 본문은 문서·버전별 행을 공유하고 Case Evidence가 참조합니다. 충돌 해결과 상태 변경은 함께 저장합니다.

재현 범위

현재 전체 snapshot·절차 목록·모든 grounded_claims를 DB에 영구 보관하지는 않습니다. 완전한 사후 재현을 보장하지 않습니다.

검수 진단과 외부 추적#

credential이 있을 때 Langfuse에 모델·토큰·지연·case_id·행동 코드와 검수 이슈의 코드·경로·심각도·담당 구성요소·재작업 대상을 보냅니다. 이슈는 앞 20개와 전체 개수를 기록하며, 입력 글·OCR·prompt·evidence·검수의 자유 이유 문장은 보내지 않습니다. 판단 기록은 실제 Langfuse trace ID와 연결합니다. 코드에서 고정한 blocker 목록 관련 제외와 다른 계약 반려는 구분해 남깁니다.

개인정보와 문서#

BE가 자유글에서 식별번호·연락처·주소 등을 가리고, 이름임을 밝힌 표현의 일부를 규칙으로 가립니다. 모든 문장 속 이름을 탐지하는 것은 아닙니다. 결과 확인·충돌 확인 화면에도 [주소] 같은 가림 표시가 그대로 나오며 원래 글자로 되돌리지 않습니다. 입력 원문은 재시도와 충돌 확인을 위해 서버 DB에만 남습니다. 문서 모델용 가림과 제출용 주민번호 뒷자리 가림 정책은 서로 다릅니다. 원문과 OCR 텍스트를 추적 도구로 보내지 않습니다.
