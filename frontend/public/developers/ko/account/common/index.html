머리말에서 내 정보 열기#

홈·서류함·기록 머리말의 사람 버튼으로 /mypage에 들어갑니다. 가게 요약 카드와 저장된 업종·임차·직원·대출·계약·폐업 시기를 읽습니다. 아직 정하지 않은 폐업 시기는 그대로 표시하며, 진단 뒤 정해지는 원상복구 범위·철거 여부는 이 목록에 섞지 않습니다.

조회와 정정 경로#

내 정보는 조회 화면입니다. 여기서 가게 정보를 직접 고치지 않고 바뀐 사실은 할 일 결과 입력으로 전달합니다. 기존값과 비교·검수·필요한 충돌 확인을 거쳐 반영합니다. Case 없음과 조회 실패를 나눠 보여주며 양쪽에서도 로그아웃할 수 있습니다.

로그아웃과 기기 정리#

실제 세션은 제한 시간 안에서 POST /logout을 시도한 뒤 브라우저 토큰과 진단 답을 지우고 /login으로 이동합니다. 서버 요청 실패 때도 기기에서는 로그아웃하며 가짜 세션은 서버 요청을 생략합니다. 리본 로그아웃은 카카오계정 로그아웃이나 회원 탈퇴·가게 자료 삭제가 아닙니다.
