2026년 11월 11일까지 이어지는 서비스 변경을 문서에도 반영합니다.

코드 기준 4188520 · 확인 2026-11-11

갱신 원칙#

개발 문서와 안심가이드는 frontend/public 아래의 정적 HTML이 원본입니다. 빌드할 때 다시 만들지 않으므로, 서비스가 바뀌면 해당 페이지의 HTML을 직접 고칩니다. API 필드와 요청·응답의 최신 기준은 서버가 코드에서 만드는 OpenAPI(/docs)입니다.

갱신 순서#

  1. git fetch 후 최신 develop과 로컬 작업을 보존해 반영합니다.
  2. 변경된 화면·API·상태·에러·모델 경로와 관련 테스트를 확인합니다.
  3. frontend/public/developers/ko 아래 해당 페이지의 설명을 고칩니다. 안심가이드는 frontend/public/safety 아래에 있습니다.
  4. 고친 문장을 같은 묶음의 search-index.json에서도 고칩니다. 페이지를 새로 만들면 manifest.json에도 넣습니다.
  5. npm run build 뒤 npm run preview로 페이지·검색·링크를 확인합니다.
  6. 확인한 버전과 변경 이력을 기록합니다.

확인 명령#

Shell
cd frontend
npm run build
npm run preview   # /developers/ko/home/ 과 /safety/ 를 열어 확인

사람이 확인할 것#

문서를 자동으로 만들지 않아서 코드와 어긋나도 빌드가 실패하지 않습니다. 동작을 바꾼 PR은 리뷰에서 관련 문서 문장이 함께 바뀌었는지 확인합니다. 실제 LLM 성능과 최신 정책 적합성은 별도로 검토합니다.
