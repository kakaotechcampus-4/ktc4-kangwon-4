HTTP 상태#

성공한 HTTP 응답도 업무 결과가 FAILED일 수 있습니다. 반대로 409는 모델 판단 실패가 아니라 현재 요청을 접수할 수 없는 상태일 수 있습니다.

HTTP대표 상황화면 처리
400카카오 인가 코드 등 로그인 요청 거절새 로그인으로 인가 코드 재발급
401토큰 누락·만료·잘못된 유형재발급 또는 로그인
404Case·이력·문서가 없음현재 Case와 번호 재확인
409오래된 판단·진행 중 제출·미해결 충돌·완료 Case최신 상태 조회, 허용된 흐름으로 이동
422형식·현재 조건·파일·점검 상태 불일치내용과 조건 확인
502카카오 설정·연결 오류 또는 문서 모델·OCR 실패로그인 오류와 서류 읽기 실패를 구분해 안내

서류 안전 검사 코드#

422의 detail이 객체일 수 있습니다. FE ApiError는 detail.code를 읽어 안내를 나눕니다.

detail.code처리
AGENT_SAFETY_REFUSE같은 파일 재시도를 권하지 않고 다른 파일·내용 확인
AGENT_SAFETY_CRISIS_SUPPORT진행 상태를 보존하고 상담 창구 안내

업무 결과#

결과 조회의 result 7종과 Case 조회의 judgment_status는 서로 다른 계약입니다.

result의미
PENDING판단 처리 중
UPDATED상태 변경 반영
NO_CHANGE이번 입력으로 바뀐 값 없음
NEEDS_MORE_INFO추가 확인 질문
CONFLICT기존 사실과 다른 후보, 사용자 선택 필요
FAILED실패 및 복구 정보 확인
PROCEDURES_COMPLETED등록 절차 안내 종료, 홈으로 이동
