무엇을 검증하는가#

자동 테스트는 모델 응답을 대체해 계약·저장·보호 동작을 확인합니다. 격리 MySQL 테스트도 포함됩니다. 테스트 통과가 실제 LLM 정확도나 실제 사장님의 사용성을 보장하지 않습니다.

실행 방법#

프로젝트 테스트는 실제 모델을 호출하지 않습니다. 실제 LLM 평가 스크립트는 호출 수와 비용을 확인하는 별도 규칙을 따릅니다.

Shell
# Frontend
cd frontend
npm test
npm run lint
npm run build

# 실제 FE·BE·MySQL 브라우저 검사(Playwright, Docker 필요)
npm run test:e2e

# Backend: Python 3.12, 테스트 의존성과 Docker 필요
cd ../backend
python -m pytest tests -q

# 문서 소스와 계약·링크 확인
cd ../frontend
npm run docs:check
