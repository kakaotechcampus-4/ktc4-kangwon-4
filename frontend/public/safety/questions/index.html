12개의 질문

Q.리본이 폐업을 대신 결정하나요?

아니요. 리본은 폐업을 결심한 개인 카페 사장님의 상황을 정리하고 다음 할 일을 안내해요. 폐업 여부, 계약과 합의, 실제 실행은 사장님이 결정해요.

Q.리본이 이해한 내용이 다르면 어떻게 하나요?

결과 화면에서 다르게 이해한 내용을 직접 적어 바로잡을 수 있어요. 이전에 확인한 사실과 새 답이 충돌하면 어느 값을 쓸지 선택을 요청할 수 있어요. 이미 반영된 결과의 [맞아요]는 저장 전 승인을 뜻하지 않아요.

Q.지원금을 받을 수 있다고 확정해 주나요?

현재 리본은 지원금 자격·금액·지급 여부를 확정하지 않아요. 지원사업의 요건과 현재 접수 여부는 해당 기관의 최신 안내로 확인해야 해요. 서비스에 기록한 1차 심사 결과도 최종 지급 확정과는 달라요.

Q.서류를 올리면 기관에도 제출되나요?

서류함에 올리고 점검하거나 ZIP을 내려받는 것은 기관 제출과 별개예요. 기관이 요청한 자료와 제출 방법을 확인한 뒤 사장님이 직접 제출해야 해요.

Q.모든 개인정보가 자동으로 가려지나요?

아니요. 입력 글의 일부 번호·연락처·주소 등과 이름임을 명시한 일부 표현을 규칙으로 가려요. 모든 문장 속 개인정보를 찾아내는 것은 아니에요. AI가 읽는 자료와 제출용 파일의 가림 범위도 달라요. 불필요한 개인정보는 처음부터 넣지 말고 제출 파일을 직접 확인해 주세요.

Q.서류함에서 삭제하면 원본 파일도 모두 없어지나요?

현재 삭제는 서류함 목록에서 제외하고 기존 점검 결과를 초기화하는 동작이에요. 서버에 남은 처리 PDF·분석 캐시까지 완전히 지우는 기능은 아니에요. 문서 삭제를 모든 저장 자료의 영구 삭제로 이해하지 않도록 안내해요.

Q.AI 안내는 언제나 맞나요?

AI가 잘못 읽거나 이해할 수 있어요. 리본은 검수 절차를 두고 불확실한 내용은 다시 묻지만, 정확성을 보장하지는 못해요. 이름·금액·날짜와 중요한 계약 내용은 원본 및 담당 기관 안내와 대조해 주세요.

Q.자동으로 읽지 않은 파일은 계속 다시 올리면 되나요?

안전 검사로 처리를 멈췄다는 안내라면 같은 파일을 반복해서 올리지 말아 주세요. 서류에 관계없는 내용이나 처리할 수 없는 요청이 들어 있는지 확인하고 다른 파일을 골라 주세요. 일반적인 연결 오류나 읽기 실패와는 대응 방법이 달라요.

Q.판단에 실패하면 처음부터 다시 해야 하나요?

화면에 표시된 복구 방법을 먼저 확인해 주세요. 저장된 입력으로 다시 판단할 수 있는 경우와 내용을 보완해야 하는 경우를 구분해 안내해요. 모든 실패가 같은 입력의 재시도로 해결되지는 않아요.

Q.준비했어요를 누르면 철거까지 끝난 건가요?

아니요. 준비 확인과 실제 공사 진행은 나눠 기록해요. 실제로 끝낸 준비만 알려주시고, 진행 상태를 물으면 현재 상태를 골라 주세요. [아직 …]은 완료로 저장하지 않아요.

Q.등록된 절차를 모두 마치면 폐업 업무도 끝인가요?

리본에 등록된 절차 안내가 끝났다는 뜻이에요. 실제 기관 신고·지원금 지급·세금 정산의 완료 보증은 아니에요. 로드맵의 남은 할 일과 서류·기록을 확인해 주세요.

Q.내 가게 정보와 로그아웃은 어디서 보나요?

화면 위 사람 버튼을 누르면 [내 정보]에서 볼 수 있어요. 정보가 달라졌다면 할 일 결과로 알려주세요. 로그아웃은 기기의 로그인 정보와 진단 중 답을 지우며 회원 탈퇴나 자료 삭제는 아니에요.
